## Reproduce

Use Node 22+, `npm ci` and Playwright Chromium. An existing Chromium can be selected with `BOARDMAP_BROWSER`. Set `HACKRF_CACHE` and `CORNE_CACHE` to git caches containing the objects below; the demo script can fetch them.

```sh
npm test
npm run test:e2e -- --base HEAD --head HEAD
npm run test:e2e -- --fixture
npm run test:e2e -- --fixture --removed
npm run test:e2e -- --repo "$HACKRF_CACHE" \
  --base f6598e7b14b7ec539126479e9c6d095c668a534e \
  --head 3bdc5547004c8244de5f37104410c363854e5634
npm run test:e2e -- --repo "$CORNE_CACHE" \
  --base a935f345c5e824aeaaa8f624ae2134fae47e128e \
  --head eaf6e072fe273c2cfd64690de135ddb7ffe870f9 \
  --board pcbs/corne-cherry/hotswap/corne-cherry.kicad_pcb
npm run test:e2e -- --repo "$CORNE_CACHE" \
  --base eaf6e072fe273c2cfd64690de135ddb7ffe870f9 \
  --head eaf6e072fe273c2cfd64690de135ddb7ffe870f9
npm run test:e2e -- --repo "$HACKRF_CACHE" \
  --base f6598e7b14b7ec539126479e9c6d095c668a534e \
  --head 3bdc5547004c8244de5f37104410c363854e5634 \
  --board hardware/LNA915/LNA915.kicad_pcb
node scripts/capture-net-labels.mjs "$HACKRF_CACHE"
```

The capture command checks the counts, all six disclosed labels, R62's Metadata classification, absence of pin rows, phone bounds and browser errors. It closes its browser and ephemeral loopback server.

## Observed proof

All 48 unit tests pass. A label-only `+5V` to `VSYS` edit to the real Corne fixture previously produced six false electrical changes. It now produces zero changed parts and one explicit net rename, in either direction. An autogenerated-net spelling upgrade also produces no false changes.

The match requires a unique, identical set of component pins on each board across both revisions. Added and removed parts participate. A moved pin, changed load membership, ambiguous match or existing destination name prevents normalization. Sheet-prefix normalization runs first. The JSON preserves the original pin names in each part's before/after records and reports proved pairs in `netRenames`.

HackRF's three label-only renames remove six parts from the Electrical tier. J1 becomes unchanged; five parts retain their other changes as Metadata. U23 has 12 real pin changes instead of 15, while its reach remains 205 neighbors with all 76 VCC loads. The header's head-net count remains 379. Corne cherry remains at 180 head parts, 12 electrical changes, 18 changed parts and 102 unchanged affected parts.

Older media galleries preserve their historical captures and counts. The source designs retain their upstream licenses. Full schematic comparison, copper rendering, DRC/ERC and simulation remain outside this version.
